Automação Inteligente de E-mails com Gmail

O DispEmail permite que envie e-mails personalizados para listas de contactos de forma automática e segura, utilizando a infraestrutura robusta do Google.

Ver Manual do Usuário Termos e Privacidade

Guia de Início Rápido

Siga estes passos para começar a enviar e-mails em minutos.

1

Faça login com sua conta Google e autorize as permissões.

2

Carregue a sua planilha Excel ou CSV com os contactos.

3

Configure o modelo de e-mail e clique em "Iniciar Envio".

Política de Privacidade

Versão 1.0 — 14 de Março de 2026

1. Informações que Coletamos

O DispEmail coleta apenas as informações estritamente necessárias para o funcionamento do serviço:

  • Informações de Perfil do Google: Nome, endereço de e-mail e foto de perfil (através dos escopos email e profile).
  • Dados de Envio: Conteúdo das mensagens e listas de destinatários fornecidas por você através de planilhas.

2. Como Utilizamos seus Dados

  • Autenticação e Licença: Validamos se possui uma licença ativa através do seu e-mail.
  • Envio de E-mails: Utilizamos o acesso via gmail.send para enviar mensagens conforme suas instruções.
  • Não Compartilhamento: Nenhum dado da sua lista ou conteúdo é enviado para nossos servidores. O processamento é 100% local.

3. Uso de APIs do Google

O uso de informações recebidas das APIs do Google pelo DispEmail obedecerá à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Segurança e Retenção

Os tokens de acesso são armazenados de forma segura e criptografada no Windows Keyring. Você pode excluir todos os dados clicando em "Sair" (Logout) no aplicativo.
